# 여정산

> 여정은 추억으로, 정산은 깔끔하게 — **여정** + **정산**

구글 시트에 결제 내역을 적으면, GitHub Actions가 시트를 읽어 정산하고 GitHub Pages로 보여줍니다.

## 시트 형식

첫 행은 헤더입니다.

| 여행 | 일자 | 결제자 | 항목 | 금액 | 통화 | 정산 대상 |
|---|---|---|---|---|---|---|
| 오사카 2026 | 2026-10-03 | 민수 | 숙소 | 450000 | KRW | 전원 |
| 오사카 2026 | 2026-10-03 | 지수 | 저녁 | 8200 | JPY | 민수, 지수 |
| 오사카 2026 | 2026-10-04 | 민수 | 택시 | 30000 | KRW | 지수:2, 민수:1 |

- **여행**: 같은 이름끼리 한 여행으로 묶입니다. 다음 여행은 같은 시트에 이어서 적으면 됩니다. 비우면 "여행" 하나로 취급합니다.
- **일자**: `2026-10-03` 형식을 권장합니다. 여행의 가장 빠른 날짜가 1일차입니다.
- **통화**: 비우면 KRW입니다. 외화는 `rates.json`에 환율을 적어야 합니다.
- **정산 대상**: 비우거나 `전원`이면 참가자 전체가 균등 분할입니다. 이름을 쉼표로 나열하면 그 사람들만 균등 분할합니다. `이름:비율`이면 비율대로 나눕니다.
- 참가자는 결제자 또는 정산 대상에 한 번이라도 나온 사람입니다. 한 번도 안 나온 사람은 `전원`에 포함되지 않습니다.
- 나눠떨어지지 않는 1원 단위는 결제자부터 1원씩 더 부담합니다.

## 설정

1. 시트: 파일 → 공유 → **웹에 게시** → 해당 시트 탭, 형식 **CSV** → 게시 → 링크 복사
2. 저장소 Settings → Secrets and variables → Actions → `SHEET_CSV_URL`에 그 링크를 등록
3. Settings → Pages → Source를 **GitHub Actions**로 변경
4. Actions 탭에서 워크플로를 수동 실행 (이후 push, 매일 자정에 자동 갱신)

## 로컬 확인

```
node scripts/build.mjs --file sample.csv
npx serve site
```

빌드 결과 `site/data.json`은 커밋하지 않고 배포 때만 생성됩니다.
